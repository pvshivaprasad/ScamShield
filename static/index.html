EVALUATION

Measure honestly.

Development metrics help spot regressions. Synthetic tests are not a substitute for independent real-world validation.

What the numbers do—and don't—tell us

The Indian-style transfer set is synthetic and partly aligned with the hand-built rules. The hand-written sample is small. Scores on those sets may overstate real-world performance.

Before relying on ScamShield for decisions, evaluate it on a consented, independently labelled, representative dataset and measure false positives and false negatives.

THE METHOD

Evidence before certainty.

ScamShield combines statistical text patterns with clear rules, then explains the signals it found.

01

Read the message

Text is checked for word and character patterns that often appear in scam messages.

02

Combine signals

A TF-IDF + Logistic Regression model is blended with explainable pattern rules for common fraud tactics.

03

Explain the result

The app highlights warning signs and suggests safer steps. The verdict is an estimate, not a guarantee.

Always verify independently

Never share an OTP, password or UPI PIN. Open the official bank app yourself rather than following message links. If money has been lost to cyber fraud in India, call 1930 and report at cybercrime.gov.in.
